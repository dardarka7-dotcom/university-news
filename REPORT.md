## 2. Описание приложения

«Университетские новости» — учебное веб-приложение, отображающее новости университетской жизни. На главной странице представлены публикации по категориям «Наука», «Студенты», «Объявления» и «Спорт». Пользователь может отфильтровать новости по категории и открыть полную версию публикации. При запросе несуществующей новости сервер возвращает ошибку 404.

Серверная часть реализована на Python с использованием Flask. HTML-шаблоны находятся в каталоге `templates`, оформление — в `static/style.css`. Автоматические тесты размещены в файле `tests/test_app.py`.

## 3. Используемые инструменты

- **Python 3.12** — язык программирования;
- **Flask** — веб-фреймворк;
- **pytest** — запуск автоматических тестов;
- **Git** — система контроля версий;
- **GitHub** — удалённый репозиторий;
- **GitHub Actions** — автоматизация CI/CD.

## 5. Конфигурация CI/CD

Файл конфигурации: `.github/workflows/ci.yml`.

Workflow запускается после каждого `push`, а также при создании или обновлении Pull Request. В среде `ubuntu-latest` выбирается Python 3.12, устанавливаются зависимости, выполняется проверка синтаксиса командой `python -m compileall -q app.py tests`, затем запускаются тесты командой `python -m pytest -v`.

Последовательность pipeline:

**Push → Checkout → Install dependencies → Build → Test**

Если сборка или тесты завершаются с ошибкой, запуск отмечается как неуспешный. Таким образом, ошибки можно обнаруживать автоматически после отправки изменений в репозиторий.
