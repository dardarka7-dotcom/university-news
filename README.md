# Университетские новости

Учебное веб-приложение на Python Flask для публикации университетских новостей. Проект подготовлен для варианта 24 СРОП по дисциплине «Прикладные аспекты DevOps».

## Возможности

- главная страница со списком новостей;
- категории: наука, студенты, объявления и спорт;
- фильтрация по категории;
- отдельная страница каждой новости;
- понятная страница ошибки 404 для несуществующей новости;
- автоматическая проверка проекта через GitHub Actions после каждого `push`.

## Технологии

- Python 3.12
- Flask
- pytest
- Git и GitHub
- GitHub Actions

## Запуск на компьютере

1. Установите Python 3.12 или более новую совместимую версию Python 3.
2. Откройте терминал в папке проекта.
3. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

4. Активируйте его в Windows:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   Если используете командную строку Windows (cmd):

   ```bat
   .venv\Scripts\activate.bat
   ```

5. Установите зависимости и запустите приложение:

   ```bash
   python -m pip install -r requirements.txt
   python app.py
   ```

6. Откройте в браузере адрес `http://127.0.0.1:5000`.

## Локальное тестирование

В активированном виртуальном окружении выполните:

```bash
python -m pytest -v
```

В проекте есть четыре теста: загрузка главной страницы, открытие новости, проверка ответа 404 и фильтрация по категории.

## CI/CD в GitHub Actions

Workflow хранится в `.github/workflows/ci.yml`. Он автоматически запускается после каждого `push`, а также при создании или обновлении Pull Request.

Pipeline выполняет следующие действия:

1. Получает исходный код репозитория.
2. Настраивает Python 3.12.
3. Устанавливает зависимости из `requirements.txt`.
4. Выполняет Build: проверяет синтаксис Python-командой `compileall`.
5. Выполняет Test: запускает четыре автоматических теста через `pytest`.

Если шаг завершается с ошибкой, GitHub Actions отмечает запуск как неуспешный и прекращает последующие шаги этого job.

## Загрузка на GitHub

После создания пустого репозитория на GitHub откройте терминал в папке проекта и выполните команды:

```bash
git init
git add .
git commit -m "Create University News app and CI pipeline"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/university-news.git
git push -u origin main
```

Замените `YOUR-USERNAME` на свой логин GitHub. Если Git сообщает, что удалённый репозиторий уже настроен, проверьте его командой `git remote -v`, а затем используйте правильный URL.
